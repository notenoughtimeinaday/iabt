Know what you are getting.

Where is my work saved?

Jericho saves conversations and private files in your account. Data entered inside a downloaded browser app may stay only in that browser or device. Cloud project storage does not automatically synchronize that app’s records. Use the app’s available export tools and keep backups.

What kinds of files can Jericho read?

Source review supports bounded UTF-8 text and code files. PDF, Office, archives and media may be stored but are not interpreted by this source-review feature. It produces a source inventory and literal requirements, not a general security or correctness audit.

What is outside the first release?

Automatic app-store submission, autonomous changes to Jericho’s own code, video generation, unrestricted service integrations and a managed multi-user backend for every generated app are outside this product’s first release.

What does the owner’s package contain?

Versioned source, a staging-targeted frontend build, dependency notices, deployment instructions, a customer guide, a launch checklist and file checksums. It contains no account database or infrastructure credentials. See OWNER-RELEASE.md before operating or distributing it.
